# Agentflow Graph Orchestration

## Overview
Coordinates multi-node visual agent workflows, mapping UI nodes (agents, LLMs, prompt templates, chains) into a deterministic execution graph with dynamic branching and state passing.

## Key Capabilities
- Topological sorting and parallel branch execution.
- Conditional edge evaluation and supervisor agent delegation.
- Cycle detection and runaway iteration caps.
